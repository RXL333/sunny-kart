# 晴空卡丁车：实施与验收

## 需求依据
用户要求依据分享对话制作卡通卡丁车游戏，允许加入创意，已打开 Blender。已通过 read_thread 读取原对话中的用户决定：先做电脑网页端；卡通、简单操作、休闲娱乐；第一版纯竞速，漂移与氮气为核心；攻击道具以后添加；轻度碰撞推挤、减速，不容易翻车；多端同步和低延迟是重要要求。原对话中的助手长规格仅返回内容引用占位符，因此未可核对的细节采用本文件明确的实现。

## 平台与方向
交付电脑网页端单人比赛与好友房间，Three.js + Vite + Node WebSocket 服务；原创明快圆润卡通美术。Blender 产出狐狸、兔子、熊猫与赛车，保存 .blend 和导出 .glb。本地/局域网可运行；公网多人需要另行部署，不能把本机低延迟测试当作公网保证。

## 模块和依赖
1. `src/game/track.js`：闭合赛道路程采样、赛道内容位置。
2. `src/game/race.js`：倒计时、驾驶、漂移蓄力、氮气消耗/补充、轻度碰撞、AI、圈数、排名、结算。
3. `src/ui.js`、`src/style.css`：主菜单、选择车手、HUD、暂停、帮助、结算、触屏控制。
4. `src/world.js`：赛道、海岛景观、光照、车辆与追尾镜头。
5. `assets/source/`、`public/models/`：Blender 可编辑源与运行模型。
6. `src/main.js`：渲染循环、输入、模块联动、音效与持久化最佳成绩。
7. `server/index.js`、`src/network.js`：2-8 人六位房间号、房主开场、60Hz 服务器权威模拟、20Hz 快照、30Hz 输入、本地预测和远端插值、延迟显示、掉线转 AI 与房主移交。

## 验收
- 依赖可安装，生产构建可通过。
- 驾驶输入、暂停/继续、漂移蓄力释放、氮气、AI、三圈结算和重开可工作。
- 两个真实 WebSocket 客户端能加入同一房间，独立控制、同步比赛、处理断线。
- 关键规则通过 Node 自动测试；在浏览器实测菜单、比赛、HUD与无错误加载。
- 检查桌面及窄屏布局，检查 3D 视觉，保留实际截图。
- 测试报告明确区分通过、失败、未执行；跨设备、公网高延迟与长时稳定性单列，不宣称已经测过。
