# 多赛道与自由按键

目标：在现有晴空大环岛之外增加三条有不同路线和环境的赛道，设置中支持逐个拖动手机触屏按键并保存，验证后发布 GitHub Pages。

## 实施范围

- 赛道目录：保留原岛，增加糖果丘陵、海湾环岛、星光峡谷。每条路线独立设计，保持闭环、路面连续、坡度和弯道适合现有物理模型；加速带与能量路线有节奏变化。
- 视觉：三种对应的卡通环境和路边地标，控制手机渲染开销。切换地图时释放上一场景资源。
- 选择与联机：新增赛道选择界面，独立记忆个人最佳；房主建房时决定赛道，服务端向所有玩家同步同一赛道 ID。保留旧客户端默认赛道兼容。
- 按键编辑：设置内进入全屏布局编辑，支持六个按键独立拖动、保存、取消和恢复预设；横竖屏分别保存归一化位置，适配安全区与窗口尺寸。编辑期间不产生驾驶输入。
- 发布：沿用现有 GitHub Pages 工作流和 Render 后端，不购买或迁移云服务器。

## 依赖顺序

先确定赛道数据接口与按键数据结构；地图数据、环境和按键编辑并行；主流程接入赛道选择和联机同步；执行测试和浏览器验收后提交、推送并确认部署。

## 验收

- 四条赛道均可选择、航拍、开始和重新比赛；路线、装饰和名称匹配。
- 全部路线闭合、无自交，坡度曲率有界，路面不被地形覆盖，拾取物位于有效车道。
- 多人房间使用房主选中的赛道，未识别 ID 不会造成不同地图比赛。
- 拖动时不触发油门等输入；保存后实际驾驶按键位置一致，刷新仍保留；取消不改变原布局；恢复默认有效。
- 手机横屏与竖屏切换、不同视口、大小设置后按键仍在可触达范围内。
- 运行受影响的单元与服务器集成测试、构建；浏览器实际检查菜单、地图、设置与拖动；未进行的实体手机或跨设备体验单独标明。
