# 手机横屏适配与验收

2026-10-21：在现有竞速规则上适配手机，沿用 GitHub Pages + Render 部署。

## 设计
- 真实触屏设备与手机横屏均显示触控；左手左右转向，右手漂移、氮气、刹车和手动油门。手机默认自动油门，可随时切回手动。
- 多指并行输入、同一按键多指释放、移出按键、取消/失焦/旋转均不能留下卡住的转向或油门。
- 横屏采用紧凑 HUD，操作区避开车辆和中央道路、刘海及系统手势区域；竖屏提供可跳过的横屏建议。
- 全屏与横屏锁定按浏览器能力尝试；不支持锁定时仍可手动旋转。单人旋转提示时暂停，联机不暂停全房间。
- 相机使用实际画布尺寸，旋转后保持比例；触屏适当限制像素比和阴影分辨率。
- 设置提供标准/左手动作布局、转向灵敏度35%–100%、按键56–84px、不透明度35%–100%、底边距离8–48px、自动油门、自动/流畅/清晰画质和总音量。立即应用、校验存储、刷新恢复和一键重置；默认值由硬件能力决定，缩小桌面窗口不会偷偷开启油门。

## 模块
- `src/mobile.css`：手机横/竖屏、平板、短屏菜单和 HUD、安全区及按键尺寸。
- `src/touch-controls.js`：多指输入与清理；`src/mobile.js`：设备状态、旋转提示、全屏与横屏尝试。
- `src/ui.js`、`src/main.js`：触控集成、默认自动油门、提示期间单人暂停与恢复。
- `src/world.js`、`src/viewport.js`、`index.html`：视口、相机、渲染成本。
- `src/settings.js`、`src/settings.css`：设置面板、存储与恢复默认；`src/input.js`、`src/audio.js`应用灵敏度和音量。

## 必须检查
- 输入回归：转向、油门+转向+漂移/氮气、多指释放、取消与失焦清理；此前左右方向回归仍通过。
- 视口计算与相机比例；39项既有自动检查及新增行为检查，生产构建。
- 浏览器 390×844、844×390、667×375、932×430、1024×768，以及桌面回归；检查按钮可见、最小44px、越界/重叠、画布比例和旋转后残留输入。
- 保存横/竖屏实测截图；更新 Pages 并核对实际发布状态。
- 模拟视口不等于真机：iOS/Android全屏、方向锁、多指硬件触感和帧率实测单列待验收。

技术依据：[Screen Orientation](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)、[Fullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)、[safe-area环境变量](https://developer.mozilla.org/en-US/docs/Web/CSS/env)。

## 本轮验收
- 自动测试：57项通过，0失败、0跳过；包括18项新增声音、输入、自定义设置、多指和视口检查。生产构建通过，Three.js保留约595KB的vendor体积提示。
- 真实GLB投影：三位车手在三种手机横屏尺寸、多种速度/偏移/漂移角度和赛道采样点下，完整车体位于画面45%–83%高度，宽度低于20%；短横屏镜头避免急弯后方道路采样挤近赛车。
- 浏览器尺寸：390×844、844×390、667×375、932×430、1024×768、1280×720。手机/平板画布CSS尺寸与渲染比例一致；横屏触控、菜单、HUD、设置入口可用。
- 极限配置：667×375、84px按键、48px底距、35%不透明度与镜像布局，触控区未越界或互相覆盖；自动油门移到顶部，底部仪表避开赛车。
- 浏览器交互：触控转向释放无残留；竖屏开赛计时保持00:00；旋转横屏后恢复；设置中保持00:01.59，关闭后继续至00:01.82；调整布局/灵敏度/画质/按键参数并刷新后仍保留；恢复默认及底部选项可达。
- 多指并行、重复手指、滑动、取消、失焦和旋转清理由事件模型自动测试覆盖，未用真实手机同时多指按压验证。
- 尚未执行：iOS/Android真机全屏与方向锁、刘海/系统手势实机验证、持续发热/耗电/低端手机帧率。桌面浏览器视口验证不能替代这些项目。
