# 电脑键位与设备设置

目标：保留手机触屏界面和保存的按键位置，自动识别实际输入方式；电脑显示驾驶键位提示，可在设置中改键，提示与输入共用映射。

- 映射单独存储，不迁移或覆盖已有手机布局。支持油门、刹车、左右转向、漂移、氮气、自动油门、暂停和重新比赛，每个功能最多两个键。
- 设置按手机触控和电脑键盘分区；按键录制时停止驾驶输入，拒绝冲突和浏览器组合快捷键，支持取消、恢复默认和保存失败提示。
- 主菜单、比赛底栏、氮气、漂移、自动油门和帮助说明共用同一映射；电脑窗口变窄仍显示键位，手机保持原触控界面。
- 设备识别使用指针能力和实际输入，支持手机旋转与带触摸屏的电脑。切换输入方式时清空旧输入。
- 验证自定义按键实际驾驶方向与油门刹车、快捷操作、即时提示更新、刷新恢复、冲突取消、存储异常、设备识别，以及原手机布局回归。执行测试、构建和浏览器检查后发布 GitHub Pages。

依赖：先统一映射接口；映射与设置并行开发；主输入和提示接入；回归、实际浏览器验收与发布。后端协议不变，无需重新部署 Render。
