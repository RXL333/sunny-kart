- 房主创建房间时确定赛道，服务端在房间、开赛和快照中同步赛道 ID；不识别新赛道的旧客户端收到刷新提示。
- 设置中拖动六个触屏按键；保存、取消、恢复预设；横竖屏各自记录。位置归一化并适配安全区，重叠布局不能保存，屏幕缩小时会临时回到可用预设。

- 游戏区域抑制长按菜单、拖选、原生拖拽与误触缩放/滚动；保留表单、房间号复制、设置滚动和浏览器键盘快捷键。
- 切换地图时移除旧监听器并释放场景、模型、纹理、阴影与渲染器资源，防止过期异步模型回填。

## 发布与线上复核

目标前端：[GitHub Pages](https://rxl333.github.io/sunny-kart/)。沿用仓库推送触发的 Test and deploy GitHub Pages 工作流，后端沿用现有 Render 服务并更新多赛道协议。

线上新赛道双连接检查命令：

```text
node scripts/check-public-server.mjs https://sunny-kart-server.onrender.com candy-hills
node scripts/check-public-server.mjs https://sunny-kart-server.onrender.com bay-loop
node scripts/check-public-server.mjs https://sunny-kart-server.onrender.com starlight-canyon
```

上述公网脚本会创建并清理自身测试房间；输出单独报告服务支持的赛道、联机功能与 RTT，功能通过不代表低延迟体验通过。
