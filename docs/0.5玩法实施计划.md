# 0.5 玩法与趣味性实施

用户已确认完整玩法规划，本轮直接完成实现、验证与发布。

## 范围与顺序

1. 共享模拟：三段漂移、尾流、AI 驾驶个性、距离追赶权重、攻击双方反馈与比赛统计。竞速与道具赛保持分离；计时赛关闭尾流和随机道具。
2. 地图与表现：四图策略区提供明确的收益和代价，路面标识可辨认；漂移、护盾和保护反馈使用有界效果，保留低画质方案。
3. 联机：服务器校验投票、房主配置和再次开赛；保留队伍、赛后投票、观战；协议与客户端、后端同步升级。
4. 本地玩法：四图积分杯、可跳过的分步驾驶练习、固定挑战与外观车库。奖励只改变外观，不改变属性。
5. 整合：手机横屏界面避免占用触控区域，保留原按键布局；教程和提示跟随自定义电脑键位；旧设置及存档兼容，驾驶变更隔离旧幽灵版本。
6. 发布：必要行为回归、构建、现有浏览器流程及桌面/手机界面检查，通过后更新 GitHub Pages 和 Render。

## 模块与依赖

- 模拟：`src/game/race.js`、`physics.js`、`items.js`。
- 地图与场景：`track.js`、地图策略模块、`world.js`；模拟读取统一策略接口。
- 联机：`server/index.js`、`network.js`、`net-sync.js`、`protocol.js`；界面使用房间广播状态。
- 玩法进度：独立杯赛/挑战存储模块与玩法面板，由 `main.js` 管理赛道切换及开始/结束生命周期。
- 展示：HUD、音效、教学与结果面板；服务器确认才发放道具命中反馈和比赛奖励。

## 完成条件

- 五种道具能看懂用途、预警、命中和防御；已有受击保护明确可见，驾驶持续可控。
- 漂移档位与实际释放收益一致；尾流不自我触发、不在计时赛生效；AI 无瞬移或隐藏追赶速度。
- 四图都有可实际作用、标识与规则一致的路线选择。
- 双人房能完成投票、再次开赛、观战及配置同步；重连、输入确认与道具序列保持正确。
- 杯赛累计四场积分并可继续/退出；挑战只按真实有效完赛解锁，外观选择可保存。
- 教学可开始、逐步完成和随时跳过，退出后恢复常规玩法，桌面和手机都可操作。
- 必要单元/联机行为测试与构建通过；浏览器结果如实记录通过、失败、未执行，发布 SHA 可核对。
