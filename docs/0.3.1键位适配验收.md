# 0.3.1 电脑键位与设备设置验收

日期：2026-10-21（Asia/Shanghai）。

## 完成范围

- 电脑菜单与比赛底部新增明确的加速、刹车、转向、漂移、氮气及快捷操作提示；HUD 与帮助同步读取当前映射。联机不提示不可用的暂停/重赛快捷键。
- 设置区分“电脑键盘”和“手机触控”。电脑每项功能支持主键和副键、取消录制、冲突提示、清除副键、独立恢复默认和本机保存；手机原有拖动布局和横竖屏存储保留。
- 设备识别按主指针能力与实际输入；窄电脑窗口仍使用键盘提示，触屏电脑支持切换。切换时释放原输入，录制和输入框不会误触发驾驶。
- 键盘映射单独使用 sunny-keyboard-v1，不覆盖手机设置或布局。存储失败显示提示；浏览器组合快捷键与输入法输入不参与录制。
- 提示栏换行时根据实际高度为底部驾驶信息留空间。后端协议与游戏物理未改变，无需重新部署 Render。

## 已通过

- 全部自动化测试：101 项通过，0 失败；包含实际驾驶输入方向、独立油门刹车、自定义替换原键、映射保存恢复、冲突/取消/存储异常、独立默认恢复、隐藏分区焦点和设备切换。
- GitHub Pages 配置构建：GITHUB_REPOSITORY=RXL333/sunny-kart、VITE_SERVER_URL=https://sunny-kart-server.onrender.com，路径 /sunny-kart/ 构建通过。
- 真实 Chrome 本地页面：默认电脑设置分区；加速 W 改 I 即时更新；刹车尝试 I 显示冲突并保留原键；Esc 取消；自动油门 Q 改 T、暂停 Esc 改 P 后实际快捷操作有效；页面重载后映射保留；独立恢复默认成功。
- 844×390 电脑窗口：仍识别 keyboard，隐藏触屏按键，驾驶提示一行显示；读取实际 DOM 边界确认提示与速度/氮气无重叠。
- 手机存储、按键拖动、多指输入、横竖屏及浏览器手势的既有自动化回归通过。
