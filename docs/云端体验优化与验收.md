# 云端体验优化与验收

日期：2026-10-22（Asia/Shanghai）。本次修改保留现有卡通休闲竞速方向，包含前端和共享服务端规则，尚未推送或部署到公网。

## 完成内容

1. **联机同步与恢复**：服务端快照包含输入确认序号，客户端仅重放未确认输入，远端车辆使用快照缓冲插值。断线后最多 30 秒内恢复同一席位，期间由 AI 暂代；主动离开取消恢复，凭据会轮换并拒绝重复连接。房主移交优先在线成员。
2. **渲染性能**：根据持续帧耗时调整自动画质，恢复画质设滞后，流畅模式关闭阴影。粒子使用有界对象池与共享几何体，减少每帧临时向量，小地图缓存静态路线并以 12Hz 更新标记。
3. **加载性能**：Three.js 场景动态加载，先初始化菜单；赛车模型后台升级，不阻塞内置赛车开始驾驶。跨赛道复用三个模型的加载和优化结果，场景释放保留共享资源，失败可以重试。
4. **浏览器回归**：新增锁定版本的 Playwright，CI 在 Pages 构建部署前验证真实 WebGL、驾驶、设置、双页面联机、拾取反馈和计时赛。失败保留截图与 trace。
5. **计时挑战**：单车三圈，显示每圈用时、个人最佳幽灵及领先／落后时间。按赛道、角色、圈数和物理版本隔离成绩；校验轨迹连续性、完成状态和存储大小，保存失败保留本次页面会话最佳。该模式没有 AI、碰撞和随机道具箱。

## 氮气晶体和新道具

晶体奖励、可见性和动效均由实际采集状态驱动，每车每圈只能领取一次，下一圈刷新；本地预测不会提前隐藏或刷新晶体。拾取有吸收粒子、合成音效及氮气条浮字。事件携带实际增加量，满氮气仍可拾取并提示已满。

道具箱自动生效，单人和好友房间共用规则，每车每圈独立领取：

| 道具 | 持续时间 | 效果 |
| --- | --- | --- |
| 泡泡护盾 | 7 秒 | 减轻车辆碰撞和护栏减速，显示泡泡 |
| 能量磁铁 | 8 秒 | 扩大氮气晶体拾取范围，显示磁铁环 |
| 火箭冲刺 | 2.8 秒 | 提高加速与极速，显示火箭尾焰 |

道具 HUD 显示剩余时间，并根据实际圈数栏与自动油门按钮位置排列，避免叠住操作控件。

## 验证结果

- `npm test`：142 项通过，0 失败、跳过或取消；包含四赛道共八分钟的共享物理仿真、断线恢复、输入确认、预测不提前奖励、满氮气、跨圈刷新、资源复用以及幽灵存储与回放。
- `npm run build`：通过。Three.js chunk 超过 500 kB 的提示仍存在，没有以调整告警阈值代替优化。
- 五个真实 Chromium / SwiftShader 场景已通过：生产加载与驾驶刹车／暂停、切图与自定义键位持久化、双浏览器好友比赛、实际物理跨过拾取点后隐藏／动效／道具、计时幽灵与无交通模式。道具栏额外验证 1280×800 和 844×390 几何不重叠；计时 HUD 验证 844×390。
- 浏览器回归中修正了两个测试时序假设：起步车群可以推动车辆，刹车检查需等待交通经过；截图期间可合法取得相邻晶体，重复奖励应按单个晶体的时间戳和唯一奖励数量判断。相关场景修正后定向复验通过。
- 专用稀有状态接口只在 Vite 开发模式且 `VITE_E2E=1` 时存在；生产构建验证不包含 `__SUNNY_KART_TEST__`。

## 复跑与证据

```bash
npm test
npm run test:e2e
npm run perf:browser
```

浏览器首次安装和端口约定见 `tests/e2e/README.md`。性能脚本需先构建；报告写入忽略目录 `logs/performance/current.json`，含当前机器首次可操作时间、三次切图耗时、模型请求数和帧间隔。该脚本要求跨赛道切换后仍只有三次模型请求。

本次 Chromium 154、960×540、流畅画质、SwiftShader 测量：首次可操作 2213ms；切到糖果丘陵、晴风海湾、返回大环岛分别为 1864／1515／1451ms；三个模型合计只请求三次，页面脚本错误为零。40 帧采样的中位帧间隔为 233.3ms，P95 为 483.3ms，反映当前软件渲染机器的限制，不作为真机流畅性通过结论。

截图位于 `logs/playwright-results/` 和最后拾取／布局定向复验的 `logs/playwright-focused-results/`。性能记录来自软件 WebGL，不是移动设备性能承诺，也没有虚构优化前后的 FPS 百分比。

## 边界

需要前后端一起发布，旧 Render 服务不会自动获得新规则和恢复协议。服务器重启后内存房间仍会丢失；同步平滑不能降低真实线路的往返延迟。iOS／Android 真机、真实跨境弱网和长期公网体验仍需补验。
