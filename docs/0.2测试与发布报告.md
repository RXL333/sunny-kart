# 0.2 测试与发布记录

日期：2026-10-20。此文件记录本轮状态；首版报告保留在测试报告.md。

## 已通过
- `npm test`：39项通过，0失败、0跳过，约4.63秒。
- `npm run build`：通过，Three.js vendor有约595KB体积提示，无构建错误。
- 碰撞测试：追尾/对向侧滑/急弯内侧/静止重叠队列/整车护栏范围/能量不增加/低帧率不穿车。
- 帧率一致性：120、60、30、10FPS下相同输入的运动状态误差小于1e-6。
- 地图测试：2.135km闭环、平滑曲率/坡度、无自交、实际地形三角形与道路净空、桥下开放水面、五段区域/加速带/能量水晶布局。
- AI在新地图上三圈完赛；真实双WebSocket客户端房间、独立油门/刹车与交通推挤、房主移交通过。
- Pages独立后端URL、WSS安全协议、本地/LAN兼容、连接等待身份及退出时取消迟到房间请求通过。
- 浏览器已检查新首页、航拍全图、小地图完整缩放、山道/港镇驾驶、区域更新、车辆/护栏约束。
- 航拍发现远距道路深度闪烁，已移除道路与整幅草带的重叠，并提高航拍镜头近裁剪距离；截图复查通过。
- 驾驶方向：四种世界朝向下，真实Three.js跟车镜头投影验证键盘/触屏左右一致；浏览器复查转向、反向修正、氮气与暂停。
- 碰撞音效：短促低通噪声和低频闷响，包络平滑、强度封顶、连续触发限频；自动测试覆盖极端冲击值与高频回调。
- 公网服务保护：真实WS验证房间/连接上限、创建冷却、慢客户端背压、失联与闲置清理。
